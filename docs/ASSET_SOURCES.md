# ImpactLoop Visual Asset & License Directory

All visual assets, typography, icons, and 3D geometries used in ImpactLoop are original, procedurally generated, or open-licensed.

## 1. Typography & Google Fonts
- **Syne**: Open Font License (OFL) via Google Fonts.
- **Space Grotesk**: Open Font License (OFL) via Google Fonts.
- **Outfit**: Open Font License (OFL) via Google Fonts.
- **JetBrains Mono**: Open Font License (OFL) via Google Fonts.
- **Inter**: Open Font License (OFL) via Google Fonts.
- **Titan One**: Open Font License (OFL) via Google Fonts.

## 2. 3D WebGL Geometries & Shaders
- **Central Impact Core**: Procedurally generated Three.js `IcosahedronGeometry`, `OctahedronGeometry`, and `TorusGeometry` mesh shaders.
- **Particle Field**: Procedurally generated Three.js `BufferGeometry` particle point arrays.
- **System Nodes**: Three.js `BoxGeometry` mesh objects with HSL gradient shaders.

## 3. Icons & Utilities
- **Lucide React**: Open Source MIT License icon suite.

## 4. Proprietary Assets
