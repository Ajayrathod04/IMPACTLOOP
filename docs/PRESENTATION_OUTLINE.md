# ImpactLoop Presentation Outline (10 Slides)

### Slide 1: Title & Positioning
- **Header**: ImpactLoop: AI Change-Impact Decision Intelligence
- **Tagline**: *"See what your change sets in motion — before you ship it."*
- **Visual**: High-contrast rendering of the Spatial Decision Observatory.

### Slide 2: The Problem
- Product changes fail not at the point of edit, but due to unexpected downstream ripples across UX, support, billing, and revenue.
- Existing tools are static dashboards or simple code diff viewers.

### Slide 3: The Solution
- ImpactLoop predicts downstream consequences, surfaces verified evidence and explicit unknowns, and provides a human decision gate before release.

### Slide 4: Core Workflow Pipeline
- `PREDICT → PROVE → DECIDE → SHIP → OBSERVE → LEARN`

### Slide 5: Spatial Impact Observatory
- 3D/2D interactive spatial environment for exploring change cores, system nodes, and causal vector links with animated pulse propagation.

### Slide 6: Evidence Vault & Explicit Uncertainty
- Categorizes evidence into verified facts, probabilistic inferences, and explicit unknowns with resolution methods.

### Slide 7: Human Decision Gate & Risk Instrument
- System Risk Instrument (0-100 score, breadth, severity, uncertainty) + release guardrail checklist. AI analyzes, human decides.

### Slide 8: Closed-Loop Learning
- Post-shipping telemetry validation (Predicted vs Observed vs Delta) feeding back into organizational memory.

### Slide 9: Technical Architecture
- React + TypeScript + Three.js / React Three Fiber + React Flow 2D Fallback + Python FastAPI Backend + Risk Engine.

### Slide 10: Impact & Roadmap
- De-risking product releases, accelerating conversion velocity, reducing operational incident cost.
